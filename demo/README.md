# StudyFlow 智学伴侣 · W1 Demo 框架

> 第二十届全国大学生软件创新大赛 · 赛题1「AI 赋能学习生产力」
> 中南大学 · 计算机科学与技术 × 3 ＋ 文学院 × 1
> 版本：v0.1（第一周脚手架 / 可点击原型），**不是成品**

## 一、这是什么

按《周计划表_赛题1_AI赋能学习生产力_跨专业版.md》**W1（11.2–11.8）** 的交付做的可运行骨架：

- **界面与交互是真的**：移动端优先、4 个页面、可点击、可走完整个学习闭环。
- **AI 能力是假的（Mock）**：ASR / OCR / LLM / RAG / 跨设备都是桩函数，返回 Promise 模拟异步。
- **目的**：W1 就把「产品长什么样、闭环怎么串」钉死，让 4 个人能并行开工，而不是等后端做完再动界面。

它演示的正是初赛评分里「创新性 40 分」要看到的东西：
**采集 → 理解 → 积累 → 复用 → 反馈** 闭环、可检查可修正、控制权留给人、跨设备接续。

## 二、怎么运行

**零依赖、零构建**：直接双击 [index.html](index.html) 用浏览器打开即可（Chrome / Edge）。
不需要 npm、不需要起服务、不需要联网。

建议演示时按右上角 **「一键演示闭环」**，会自动依次完成：
录音/拍照/手写采集 → 生成结构化笔记 → 知识库检索 → 用于当前问题 → 确认跨设备接力。

右上角 **「场景：计算机科学与技术」** 可切换到 **文学院**，用于展示产品对两类异质材料的适配
（代码/公式/英文技术文档 ↔ 古籍文献/引文/手写批注/双语资料）。

## 三、文件结构与分工边界

| 文件 | 内容 | 负责人 | 后续替换点 |
|---|---|---|---|
| `index.html` | App 外壳、手机框架、4 个页面结构、Tab | B | W2 起细化交互 |
| `css/app.css` | 全部样式（低干扰学习风格、移动端布局） | B | 平板/PC 多端适配（W3） |
| `js/data.js` | 场景与语料 Mock（中南大学 计科 / 文学院 两套样本） | D | 换成真实调研语料（W4 起） |
| `js/adapters.js` | 5 个能力适配器的**接口形状** | A | **W3 Spike 后换真实实现** |
| `js/app.js` | 状态机、渲染、事件、一键演示 | B（队长串联） | — |
| `README.md` | 本文件 | 队长 | — |

设计原则：**adapters.js 是唯一边界**。只要 A 保持这 5 个方法的入参/返回形状不变，
把 Mock 换成端侧/云端真实实现时，B 的界面代码一行都不用改。

## 四、五个 Mock 适配器（A 的 W3 工作清单）

| 适配器 | 作用 | W3 / W4 待办 |
|---|---|---|

| `MockCrossDevice.handoff` | 跨设备接续 | 接 OPPO 互联开放能力 + 超级碰一碰（W9），**须用户确认** |

## 五、界面里已经落地的 5 个创新点

1. **任务闭环而非对话框**：左侧「学习闭环」进度条 + 一键演示，全程不是聊天框。
2. **可检查、可修正**：笔记每条要点可直接点击编辑；「溯源」展开原始录音/图像出处；低置信度（<0.8）标黄提示人工核对。
3. **控制权留给人**：接续页用「进度卡片」且必须点「确认接力」才推进，不自动同步。
4. **异质材料分治**：计科/文学院场景切换，同一套 UI 吃两类完全不同的材料。
5. **跨设备状态不丢**：接续页展示 手机采集 → 平板续写 → PC 导出 三段状态。

## 六、W1 验收标准（做到这些就算这周合格）

- [ ] 双击 index.html 能打开，4 个 Tab 都能切换
- [ ] 「一键演示闭环」能走完 4 个阶段且左侧进度高亮同步
- [ ] 场景切换后，采集内容 / 笔记 / 知识库 / 当前问题全部换成另一专业的样本
- [ ] 笔记要点能编辑、能展开溯源
- [ ] 知识库能检索、能把结果「用于当前问题」并显示在接续页
- [ ] 接续页必须手动确认才推进，进度 0/3 → 3/3

## 七、明确的「还没做」（别拿去当成品报）

- 没有真实 ASR / OCR / 大模型 / 向量库，全是桩
- 没有真后端、没有账号、没有持久化（刷新即重置）
- 没有真实 OPPO SDK 调用
- 没有真实用户数据；量化指标（痛点发生率 / NPS / 任务完成率 / 识别修正率 / 检索命中率）
  要等 W4–W11 在中南大学计科与文学院同学中实测才有，见《选题与创新点说明_初稿_赛题1.md》v0.2 第六节

## 八、与周计划的对应

- **W1（本框架）**：B 搭脚手架、A 定适配器接口、D 备两套样本语料
